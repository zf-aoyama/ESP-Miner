# 開発者向けドキュメント

このディレクトリはESP-Minerの開発者向け資料を提供します。ファームウェアの構成概要と主要モジュールの詳細をまとめています。これらのノートを読むことで既存のコードベースを理解し、新しいハードウェアへの適応に役立てることができます。

- [概要](overview.ja.md) – 全体的なアーキテクチャと実行時に連携する主要コンポーネントを説明します。
- [モジュール概要](module_overview.ja.md) – 重要なソースディレクトリとその役割を解説します。
- [新しいASICへの移植](porting_new_asic.ja.md) – 追加のASICハードウェアをサポートするために必要な手順をまとめています。
