# 開発者向けドキュメント

このディレクトリには ESP‑Miner の開発に役立つ情報をまとめています。ファームウェアの構成概要と主要モジュールの説明、さらに新しいハードウェアへの対応方法などを記載しています。

内容一覧:

- [概要](overview.ja.md) – ランタイムで相互に動作する主要コンポーネントを含む全体構成の説明。
- [モジュール概要](module_overview.ja.md) – ソースディレクトリとその役割の解説。
- [新しい ASIC への移植](porting_new_asic.ja.md) – 追加の ASIC ハードウェアをサポートする際の手順。
- [通信プロトコル](communication_protocols.ja.md) – Stratum、REST API、ASIC シリアルコマンドの詳細。
- [ハードウェア仕様](hardware_specifications.ja.md) – ボードで使用されるセンサーやバスアドレス、MCU 接続の一覧。

英語版のドキュメントは同名の `.md` ファイルで提供されています。
