# ハードウェア仕様

ここでは、ESP‑Miner を実行する Bitaxe ボードに搭載されている主要な周辺機器とセンサーをまとめます。

## マイクロコントローラ

- **ESP32‑S3** を使用し、UART1 が ASIC チェーンに接続されます。
- 電源系や温度センサー用に I²C バスを 100 kHz で運用しています。

## 電源管理

- **TPS546** 電圧レギュレータ（I²C アドレス `0x24`、アラート `0x0C`）。ASIC へ供給するコア電圧を制御し、入力／出力電流を監視します。
- **INA260** パワーモニタ（アドレス `0x40`）。バス電圧、電流、消費電力を計測します。

## 温度監視とファン制御

- **EMC2101**（アドレス `0x4C`）または **EMC2103**（アドレス `0x2E`）を用いて外部温度の取得とファン PWM 制御を行います。
- **TMP1075** デジタル温度センサー（アドレス `0x4A`）で補助的な温度を取得します。

## ディスプレイ

- 小型の OLED/LCD ディスプレイをオプションで搭載可能です。`display` モジュールにより制御され、AxeOS から表示のタイムアウトや輝度を設定できます。

## ASIC インターフェース

- GPIO17 (TX) と GPIO18 (RX) を使用する UART1 で ASIC と通信します。リセット用 GPIO は `CONFIG_GPIO_ASIC_RESET` によって定義できます。
- ジョブデータは [communication_protocols.md](communication_protocols.md) で説明されているプロトコルに従って送信されます。

ここに挙げた部品やアドレスは参考設計のものですが、Bitaxe のリビジョンによって若干異なる場合があります。
