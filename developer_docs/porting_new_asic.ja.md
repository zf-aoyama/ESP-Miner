# 新しい ASIC への移植

ESP‑Miner が別の ASIC モデルをサポートするための一般的な手順をまとめます。既存の BM1366/BM1368/BM1370/BM1397 向け実装を参考にしてください。

1. **ASIC ドライバを作成**
   - `components/asic/` 以下に新しいソースとヘッダを追加し、チップ固有のコマンドを実装します。`bm1366.c` と `bm1366.h` がテンプレートとして利用できます。
   - 初期化、ワーク送信、結果解析用の関数を用意します。
2. **ASIC モデルを定義**
   - `asic.h` に列挙値や設定定数（コア数、難易度など）を追加します。
   - `asic.c` の `ASIC_set_device_model` を更新して新しいデバイス名を認識し、`GlobalState` に適切なパラメータを設定します。
3. **周波数管理**
   - ASIC が動的な周波数変更をサポートする場合、`BM1368_set_frequency` に類似した関数を実装し、`ASIC_set_frequency` から参照します。
4. **ビルド設定を更新**
   - Kconfig オプションや `sdkconfig` のデフォルトを追加し、ビルド時に新しいモデルを選択できるようにします。
5. **ハードウェアでテスト**
   - `components/asic/test` のユニットテストフレームワークや `test` ディレクトリのカスタムアプリを利用して、新しい ASIC との通信を検証します。

既存ドライバの構造を踏襲し、初期化処理を更新することで、ESP‑Miner は別のマイニングハードウェアを制御できるようになります。
