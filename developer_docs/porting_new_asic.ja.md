# ESP-Miner を新しい ASIC に移植する

このガイドでは、別のASICモデルをサポートするために必要な一般的手順を説明します。BM1366/BM1368/BM1370/BM1397向けの既存実装を参考にしてください。

1. **新しいASICドライバを作成する**
   - `components/asic/`配下にチップ用のソースとヘッダを追加し、コマンドセットを実装します。`bm1366.c`と`bm1366.h`がテンプレートとして利用できます。
   - 初期化、ワーク送信、結果解析用の関数を提供します。
2. **ASICモデルを定義する**
   - `asic.h`に新しい列挙値と設定定数（コア数、難易度値など）を追加します。
   - `asic.c`の`ASIC_set_device_model`を更新し、新しいデバイス名を認識して `GlobalState` のパラメータを設定します。
3. **周波数管理**
   - ASICが動的周波数変更をサポートする場合は、`BM1368_set_frequency`に類似した関数を実装し、`ASIC_set_frequency`から参照します。
4. **ビルド設定を更新する**
   - Kconfigオプションやsdkconfigのデフォルトを追加し、コンパイル時に新しいデバイスモデルを選択できるようにします。
5. **ハードウェアでテストする**
   - `components/asic/test`のユニットテストフレームワークを使用するか、`test`にカスタムテストアプリを作成して新しいASICとの通信を検証します。

既存ドライバの構成を踏襲し、グローバル初期化ロジックを更新することで、ESP-Minerは他のマイニングハードウェアの制御にも対応できます。
