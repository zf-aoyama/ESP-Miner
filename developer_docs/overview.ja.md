# ESP-Miner アーキテクチャ概要

ESP‑Miner は Bitaxe マイニングハードウェアを制御する ESP32 用ファームウェアです。大まかな処理の流れは次のとおりです。

1. **初期化** ― 起動時に NVS から設定を読み込み、I²C や ADC、ディスプレイ、Wi‑Fi などの周辺を初期化してタスクを準備します。
2. **ネットワーク接続** ― `connect` コンポーネントが Wi‑Fi 接続や AP モードを管理し、接続後は Stratum プロトコルを用いてプールと通信します。
3. **ジョブ処理** ― 受信した Stratum メッセージを ASIC 用の仕事に変換し、UART 経由で ASIC へ送信します。
4. **ASIC 管理** ― `asic` コンポーネントにモデルごとのドライバ（BM1366、BM1368、BM1370、BM1397）があり、チェーン初期化や周波数設定、結果取得を行います。
5. **システム監視** ― 電源や温度の管理、ディスプレイ更新を周期的に行い、HTTP 経由で AxeOS という Web UI も提供します。

ファームウェアは FreeRTOS タスクを使ってネットワーク通信、ジョブ生成、ASIC とのやり取り、結果処理を分担しています。`main/main.c` が各タスクを設定してイベントループを開始します。
