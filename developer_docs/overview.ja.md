# ESP-Miner アーキテクチャ概要

ESP-Minerは、Bitaxeマイニングハードウェアを管理するESP32ファミリー向けのファームウェアです。大まかに言ってファームウェアは以下の役割を担います。

1. **初期化** – 起動時にデバイスはNVSから設定を読み込み、周辺機器（I²C、ADC、ディスプレイ、Wi‑Fi）を設定し、タスクを登録します。
2. **ネットワーク接続** – `connect`コンポーネントがWi‑Fi接続とAPモード設定を管理します。接続後はStratumプロトコルを用いてマイニングプールと通信します。
3. **ジョブ処理** – Stratumメッセージを解析してASIC用のワークに変換します。ジョブはキューに入り、UARTシリアル経由でASICへ送られます。
4. **ASIC管理** – `asic`コンポーネントには各モデル専用のドライバ（BM1366、BM1368、BM1370、BM1397）が含まれます。チェーンの初期化、周波数設定、結果の読み出しを行います。
5. **システム監視** – 電源管理、温度監視、ディスプレイ更新を定期的に実行します。設定や監視用に小さなWeb UI（AxeOS）がHTTPで提供されます。

ファームウェアはFreeRTOSタスクを利用してネットワーク通信、ジョブ生成、ASICとのやり取り、結果処理を分担します。`main/main.c`がそれらのタスクを設定し、イベントループを開始します。
