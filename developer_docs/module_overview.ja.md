# モジュール概要

主要なソースディレクトリとそれぞれの役割をまとめます。

## `components/`

ESP‑IDF のビルドシステムでは、`components` 配下の各サブディレクトリが独立したコンポーネントとして扱われます。

- **asic** ― 特定 ASIC チップ向けドライバ。`bm1366.c`、`bm1368.c`、`bm1370.c`、`bm1397.c` などがモデル固有のコマンドやシリアル処理を実装します。
- **connect** ― Wi‑Fi 接続管理、AP モード、ネットワーク設定。
- **dns_server** ― 設定 UI を AP モードで提供する際に用いる簡易 DNS サーバ。
- **stratum** ― マイニングプールとの通信を行う Stratum プロトコル実装。ジョブ解析や難易度管理、結果送信を担当します。

## `main/`

アプリケーション層のコードが置かれています。主なファイルは次の通りです。

- **main.c** ― システム初期化を行い、FreeRTOS タスクを起動するエントリポイント。
- **system.c** ― 実行時統計を記録し、電源・温度管理を行いながらグローバル状態を保持。
- **http_server/** ― AxeOS の Web インターフェースや REST API、ファームウェア更新処理を提供。
- **power/** ― 電圧・電流モニタ用 IC のドライバや ASIC コア電圧制御を含む。
- **tasks/** ― ASIC へのジョブ送信、結果受信、Stratum との連携などを行う FreeRTOS タスク群。

## `test/`

ESP32 上で実行できるユニットテストを格納します。使用方法は `doc/unit_testing.md` を参照してください。
