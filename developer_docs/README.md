# Developer Documentation

This directory provides resources for developers working on ESP-Miner. It offers
an overview of how the firmware is organized and more detailed references for
key modules. Reading these notes should help you understand the existing code
base and adapt it for new hardware.

Contents:

- [Overview](overview.md) – explains the overall architecture and the major
  components that interact at runtime.
- [Module Overview](module_overview.md) – describes important source directories
  and their purpose.
- [Porting to a New ASIC](porting_new_asic.md) – outlines the steps required to
  support additional ASIC hardware.
